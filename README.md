# Modern Computer Lab / Smart Classroom

A **Computer Graphics Lab Project** developed using **C++ and OpenGL**.

The project creates a complete 3D computer lab/classroom with student workstations, teacher setup, lighting, camera movement, projector, ceiling fans, and other classroom objects.

## Demo Video

▶️ **YouTube:** https://youtu.be/l1NLwfSdEiU

## Main Features

- 3D classroom environment
- Translation, rotation, and scaling
- Camera movement and different viewing angles
- Phong shading
- Ambient, diffuse, and specular lighting
- Point lights
- Projector spotlight
- Rotating ceiling fans
- Fan ON/OFF control
- Room light control
- Projector spotlight ON/OFF
- Student computer workstations
- Teacher and student models
- Whiteboard, projector, AC, door, and LED panels

## Controls

| Key | Action |
|---|---|
| `W` | Move Forward |
| `S` | Move Backward |
| `A` | Move Left |
| `D` | Move Right |
| `Q` | Move Camera Up |
| `E` | Move Camera Down |
| Hold Left Mouse + Move | Look Around |
| Mouse Wheel | Zoom |
| `F` | Fans ON/OFF |
| `L` | Room Lights Bright/Dim |
| `P` | Projector Spotlight ON/OFF |
